## ✨ 功能特性

### 🔍 智能风险识别
- **8大风险规则库**：覆盖违约金、解约权、管辖地、试用期、竞业限制等常见陷阱
- **自动分级**：🔴高风险 / 🟡中风险 / 🟢低风险，一目了然
- **精准定位**：显示风险条款所在行号，快速定位问题
- **法律依据**：自动引用《民法典》《劳动合同法》等法律法规
- **修改建议**：提供可直接使用的修改文案，不用再想怎么改

### ✍️ 合同自动生成
- **4大类合同模板**：买卖合同、劳动合同、房屋租赁合同、保密协议
- **智能填充**：自动生成合同编号、签署日期
- **金额转换**：自动转换中文大写金额，避免手动输入错误
- **高度可扩展**：轻松添加新的合同模板

### 📊 专业审查报告
- **风险统计汇总**：高/中/低风险数量一目了然
- **逐条详情分析**：每条风险都有说明、依据、建议
- **优先级排序**：告诉你先改哪个，后改哪个
- **导出支持**：支持导出Markdown格式报告，方便存档和分享

## 🚀 快速开始

### 1. 下载项目
```bash
git clone https://github.com/yourusername/contract-ai-pro.git
cd contract-ai-pro
```

### 2. 审查合同
```bash
# 基本审查
python scripts/review_contract.py --file examples/sample_contract.txt

# 导出审查报告
python scripts/review_contract.py --file your_contract.txt --export report.md

# 仅显示风险统计（快速筛查）
python scripts/review_contract.py --file your_contract.txt --brief
```

### 3. 生成合同
```bash
# 查看可用模板
python scripts/generate_contract.py --list

# 生成买卖合同
python scripts/generate_contract.py \
  --template 买卖合同 \
  --partyA "甲方公司名称" \
  --partyB "乙方公司名称" \
  --amount 100000 \
  --output my_contract.md
```

### 风险规则覆盖

| 规则ID | 风险名称 | 风险等级 | 说明 |
|-------|---------|---------|------|
| R001 | 违约金比例过高 | 🔴高 | 超过30%可能被法院调减 |
| R002 | 单方解约权不对等 | 🔴高 | 违反公平原则，可能无效 |
| R003 | 争议解决地不利 | 🟡中 | 增加维权成本 |
| R004 | 保密期限过长 | 🟡中 | 实际履行困难 |
| R005 | 试用期超期 | 🔴高 | 违反《劳动合同法》 |
| R006 | 竞业补偿过低 | 🟡中 | 低于法定标准 |
| R007 | 免责条款过宽 | 🔴高 | 可能被认定无效 |
| R008 | 缺少必备条款 | 🟡中 | 合同完整性不足 |
